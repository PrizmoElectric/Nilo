NILO — MANUAL DE COMANDOS
=========================
Todos os comandos são ditos no chat do Minecraft pelo MASTER (PrizmoElectric).
Variantes em pt-BR e en-US são aceitas. O prefixo "!nilo" é opcional no Discord.
Última atualização: 2026-06-05


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
NAVEGAÇÃO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

follow / me segue / vem comigo / me acompanha / fica comigo
  Nilo começa a seguir o MASTER a distância 2.

come here / vem aqui / chega aqui / vem até mim
  Nilo para o comportamento atual e caminha até o MASTER (dist=2).

closer / fique mais perto / fica mais perto / mais perto
  Nilo segue o MASTER bem de perto (dist=1).

stay / stop / wait / para / espera / não se mexa / aguarda
  Nilo para tudo e fica no lugar.

sit / senta
  Nilo agacha e fica sentado (sneak persistente).

stand up / levanta / para de agachar / fica em pé
  Nilo levanta e sai do modo sit/sneak.

wander / vagabundeia
  Nilo caminha aleatoriamente num raio de 10 blocos a cada 5s.

go explore / explora / vai explorar / começa a explorar
  Habilita exploração autônoma quando ocioso.

stop exploring / para de explorar / fica parado / não explora
  Desabilita exploração, Nilo fica parado quando ocioso.

unstuck / destravar / sai do caminho / se mexe / move-te
  Tenta se soltar quando Nilo estiver preso.

go away / vai embora / me deixa / para de me seguir / sai daqui
  Para de seguir, entra em modo idle.

help / assist / protect me / me ajuda / me protege / me cobre / me escolta
  Modo de assistência em combate: segue e ataca mobs ao lado do MASTER.

tp me / tp here / tp para mim / vem aqui agora
  Teleporta Nilo para a posição do MASTER via /tp.

tp me to you / me traz para você / teleporta eu para você
  Teleporta o MASTER para a posição de Nilo via /tp.

tp <jogador1> to <jogador2>
  Executa /tp de um jogador para outro. Aceita "me" e "you" como atalhos.

look at me / olha pra mim / me olha
  Nilo olha para o MASTER uma vez.

look at me for N / olha pra mim por N
  Nilo fica te olhando por N segundos (loop de 50ms).

look up/down/north/south/east/west
  Nilo olha na direção indicada. (pt-BR: cima/baixo/norte/sul/leste/oeste)

press button / press this / push lever / aperta / empurra
  Caminha até o botão/alavanca/placa que o MASTER está olhando e o ativa.

click/press/activate X Y Z
  Caminha até as coordenadas e ativa o bloco naquela posição.

COMBATE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

attack / ataca
  Ataca o mob hostil mais próximo em modo melee contínuo.

guard / sentinela / vigia / combat mode / melee mode / go melee
  Modo guarda: patrulha o posto e ataca mobs hostis automaticamente.

defensive / defensivo
  Modo defensivo: só luta se for atacado primeiro.

passive / passivo
  Modo passivo: não luta sob nenhuma circunstância.

use bow / archer mode / sniper mode / usa o arco / modo arqueiro
  Modo arqueiro: ataque ranged com kiting e lógica de distância.

shoot that / shoot it / atira nisso / atira nele
  Dispara uma flecha na direção que o MASTER está olhando.

ATIVIDADES

mine this / dig that / break this / mine it
  Minera o bloco que o MASTER está olhando (auto-equipa ferramenta).

tunnel [N] / escava / cava um túnel [N]
  Escava um túnel de N blocos para frente (padrão: 32, máx: 512).

stop tunnel / para de cavar / cancel digging
  Interrompe a escavação do túnel em andamento.

fish / pesca / vai pescar / começa a pescar
  Começa a pescar: lança a linha e recolhe quando fisgar.

stop fishing / para de pescar / stop casting
  Para de pescar e recolhe a linha.

farm / colhe / vai para a fazenda / farmar
  Percorre a área de fazenda configurada e colhe plantações maduras.

build shelter / build house / constrói uma casa / constrói um abrigo
  Constrói uma casa/abrigo simples com os materiais disponíveis.

sleep / dormir / dorme na cama / usa a cama
  Procura e dorme na cama mais próxima.

dance / dança / mostra seus passos
  Executa uma animação de dança.

collect my grave / pega seu túmulo / vai pegar seu túmulo / recupera seus itens
  Vai buscar o túmulo do MASTER após morte e coleta os itens.

write sign: <texto> / leave a note: <texto> / sign says <texto>
  Coloca uma placa com o texto informado. (pt-BR: escreve no sign: / deixa uma nota:)

FÍSICO

jump [N] / pula [N]
  Pula 1 vez ou N vezes (máx: 20).

move forward/back/left/right [Ns]
  Move nessa direção por N segundos (padrão: 2s, máx: 10s).
  (pt-BR: anda para frente/trás/esquerda/direita)

sprint [Ns] / corre [Ns]
  Corre para frente por N segundos (padrão: 3s, máx: 10s).

spin [N] / spin left / spin right / gira / dá uma volta
  Gira N graus na direção indicada (padrão: 360, máx: 1080).

wave / acena / balança o braço
  Acena o braço 6 vezes.

crouch / sneak / duck / agacha / abaixa
  Agacha (sneak persistente, mantém após pathfinding).

stand up / levanta / para de agachar / fica em pé
  Fica em pé e cancela o sneak.

INVENTÁRIO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

inventory / inventário / what do you have / o que você tem / mostra seus itens
  Lista todos os itens agrupados por categoria (armas, ferramentas, armadura, comida, blocos).

equip <item> / hold <item> / wield <item> / equipa <item>
  Equipa o item do inventário que contenha o nome informado.

equip this / equipa isso
  Pega o item mais próximo no chão e o equipa.

use <item> as weapon / usa <item> como arma
  Define o item como arma principal para combate.

unequip that / tira isso / desequipa isso
  Desequipa o item na mão principal.

unequip and give me / tira e me dá
  Desequipa o item na mão e joga para o MASTER.

give me that / hand it over / me dá isso / me passa isso
  Joga o item da mão principal para o MASTER.

drop all / drop everything / larga tudo / joga tudo fora
  Joga todos os itens do inventário no chão.

drop the item in my hand / joga isso fora
  Joga o item que está na mão no chão.

drop <item> / give <item> / me dá <item>
  Joga o item específico no chão.

eat this / come isso
  Coleta o alimento mais próximo e o come.

bring me <item> / get me <item> / fetch <item>
  Procura nos containers próximos (raio 32) e traz o item para o inventário.
  Suporta quantidade: "bring me 16 iron_ingot".

open it / open this chest / read chest
  Abre o container que o MASTER está olhando e lista o conteúdo.

open at X Y Z
  Vai até as coordenadas e abre o container naquela posição.

open <mod:bloco> / find <mod:bloco>
  Encontra e abre o bloco modded mais próximo no range do scan.
  Exemplo: open ae2:terminal | find ae2:drive | open the inscriber

REGISTRO DE BLOCOS E ENTIDADES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

scan [raio] / escaneia / o que tem ao redor
  Escaneia todos os blocos num raio (padrão: 16, máx: 64) e exibe os top 10.
  Salva o resultado completo em scans/scan_<timestamp>_r<raio>.txt.

echo scan [N] / repete scan [N]
  Reexibe o resultado do scan N (0 = mais recente). Aceita intervalo: echo scan 1-3.

this / what is this / what am I looking at / o que é isso
  Identifica o bloco ou entidade que o MASTER está olhando.
  Bloco → nome, posição X Y Z e stateId. Entidade → nome, tipo, hostil/passivo, HP.

this is <mod:nome>
  Ensina o nome correto (com namespace) do bloco que o MASTER está olhando.
  Exemplo: this is yigd:grave | this is create:cogwheel

blockmap <stateId> <mod:bloco> / blockname <stateId> <mod:bloco>
  Mapeia manualmente um stateId para um nome de bloco no banco de dados.
  Exemplo: blockmap 286849 create_new_age:thorium_ore

id <stateId>
  Localiza todos os blocos com aquele stateId num raio de 32 blocos e mostra posições.

<bloco> is solid / <bloco> is passable / <bloco> is walkable
  Ensina a Nilo se o bloco é sólido ou atravessável (afeta o pathfinding).
  Exemplo: thorium_ore is solid | modded_plant is passable

this is solid / this is passable
  Ensina a física do bloco que o MASTER está olhando (sem precisar saber o nome).

<bloco_a> is <bloco_b>
  Remapeia todos os stateIDs do bloco_a para o nome bloco_b.
  Exemplo: pumpkin_stem is stone_bricks

<entidade> is hostile / <entidade> is not hostile / <entidade> is friendly
  Ensina Nilo se aquela entidade é hostil ou não. Salvo no banco de dados.
  Exemplo: zombie_merchant is hostile | forest_spirit is friendly

what do you know about <bloco/entidade>
  Consulta o banco de dados para o nome informado: hostilidade, física, stateIDs.

rawblock
  Debug: exibe stateId e nome de cada bloco no ray-cast do gaze do MASTER (até 6 blocos).

NOTAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- Tudo que não bater com um comando acima é enviado para o Letta (IA), que responde
  em linguagem natural e pode acionar ações automaticamente via [ACTION: name].

- Mensagens começando com "!" (exceto "!nilo") são ignoradas silenciosamente.

- Idioma detectado automaticamente: pt-BR ou en por heurística de palavras.
