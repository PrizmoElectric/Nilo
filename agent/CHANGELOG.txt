2026-05-04 (session 4)
────────────────────────────────────────────────────────
Bug diagnosis + fix session (Prominence 2 modded server).

Crash root cause found and fixed (monitor.js):
- bot.findBlock() internally calls isBlockInSection() which runs the
  matching function with Block.fromStateId(stateId, 0) for palette
  fast-filtering. These palette-check blocks have position = null.
- New container-search matcher accessed b.position.x before any null check.
  TypeError thrown inside async setInterval callback → unhandled promise
  rejection → Node.js 25 kills the process silently with no log entry.
- The crash happened exactly 2 seconds after login (matching the 2000ms
  setInterval interval, first tick).
- Fix: check b.name first (valid on palette blocks), then guard b.position
  before accessing position for the triedContainers lookup.

Handshake improvements (nilo.js, already in codebase this session):
- forgeconfigapiport:sync_configs now responds with Buffer([0x00])
  (empty VarInt string) instead of empty buffer. Empty buffer caused
  IndexOutOfBoundsException on the server — it expected at least a VarInt.
- forgeconfigapiport:* fallback also updated to Buffer([0x00]).
- fabric:custom_ingredient_sync responds with [0x01, 0x00] (protocol
  version 1 + 0 ingredients). Was returning version 0, which the server
  rejected with "Unknown ingredient sync protocol version: 0".
- fabric:* fallback sends Buffer([0x00]) instead of empty buffer.

Proximity greet removed (monitor.js):
- Removed auto-greeting when MASTER enters range (was calling queryLetta).
  lastGreetTime and GREET_COOLDOWN_MS removed.

Container search broadened (monitor.js):
- Was only matching 'chest' and 'trapped_chest'.
- Now matches by keyword list: chest, barrel, crate, storage, bin, locker,
  safe, cabinet, trunk, box, vault, strongbox.
- triedContainers Set added — skips blocks that previously failed openContainer.

Scan command simplified (skills/scan.js):
- Removed per-block sid tracking (sidSets). Output is now just name + count.
- Unknown modded blocks shown as "unknown:<stateId>" instead of "unknown".
